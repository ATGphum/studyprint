# Studyprint

Studyprint is a four-axis study-personality quiz. It gives each person a memorable four-letter study code, a practical study playbook, and a compatibility score for studying with someone else.

## The code

- **A / C** — Alone or Collaborative
- **Q / T** — Quiet or Talkative
- **S / F** — Scheduled or Flexible
- **O / P** — Organised or Procrastinating

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build:pages
```

Pushing to `main` publishes the static export through GitHub Pages.
